\begin{abstract}
Feynman integral reduction expresses the loop integrals in a particle-physics calculation through a smaller set of master integrals. We studied how machine learning, exact identities, and shared calculations can reduce the time required to complete this calculation with Kira. We constructed 2.30 million targets with known master expansions, trained seed and row models, and developed later models using complete measured reduction cost. We retained useful seed choices and omitted learned row selection after its timing tests. Our primary comparison uses the original Kira 3.1 executable with default algorithms for the same specified physical reduction jobs.
% BEGIN PRIMARY COMPARISON
On 14 matched native requests, summed median time changes from 266.458 to 22.109 seconds, a 12.05-fold speed factor and 91.7\% time saving. Under the stated limits, default Kira completes 14 of 20 requests in all repetitions, and our method completes 20.
% END PRIMARY COMPARISON
Separate component tests give a 4.9\% learned saving against a matched fixed strategy on 43 completed native requests. For a restricted vacuum family, exact recurrences reduce a supplied-equation calculation from 1,027.781 to 1.922 seconds. Earlier 39.1\% and 8.8\% application gains use previous optimized versions as their references. We keep those secondary comparisons separate from the default-Kira result. Restricted analytic tests extend through thirteen loops; a matched default-Kira comparison for those analytic requests and general high-loop scattering remains outside the demonstrated primary result.
\end{abstract}
