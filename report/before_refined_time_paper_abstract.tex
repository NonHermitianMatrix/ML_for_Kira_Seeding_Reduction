\begin{abstract}
Integration-by-parts reduction expresses Feynman integrals in a master basis~\cite{KiraOriginal}. We combine exact reductions with a learned choice of Kira seed settings and train that choice on complete elapsed time. The model uses integral structure and the required master basis; its training cost includes unsuccessful attempts and recovery. Exact formulas handle their supported families before any prediction, while native Kira settings remain available for other inputs. The new test contains 127 requests, and the learned application completes three exact checks on 126. On 126 matched requests, the application uses 316.252 seconds against 336.610 seconds for previous choices, or 6.0\% less time. The time ratio is 0.940, with repetition interval $[0.831,0.931]$. On 82 matched requests, the application uses 265.629 seconds against 265.670 seconds for native choices, or 0.0\% less time. The time ratio is 1.000, with repetition interval $[0.971,1.008]$. On 82 matched requests, the application uses 265.629 seconds against 266.563 seconds for fixed choices, or 0.4\% less time. The time ratio is 0.996, with repetition interval $[0.979,1.014]$. The matched comparison with fixed choices does not resolve a difference beyond repetition variation. The comparison includes model use, equation generation, algebra, exact checks, and recovery; master-basis and reference preparation precede these timers. We keep the dimension symbolic and use rational values for other kinematic variables. Specified formulas and independent products extend the checked range through thirteen loops, while coupled native tests reach three loops. General high-loop scattering and globally minimum reduction paths remain unverified. Earlier local seed and equation models give separate measured savings; the application retains native row selection because the tested row models give no reliable complete-time gain.
\end{abstract}
