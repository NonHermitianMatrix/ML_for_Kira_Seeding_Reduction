\section{Conclusion}
Loop-integral decomposition can become cheaper when the method uses the algebraic structure before generating a general equation system. The added recurrence reduces supported scalar one-loop blocks with exact polynomial coefficients in the dimension. Independent-loop factorization extends this method to products of those blocks, and the existing learned selector handles its supported coupled cases. Every accepted result reaches the prepared master basis, while unsupported cases retain the native fallback.

The initial analytic-enabled comparison completes 41 of 41 requests in three repetitions. Across 41 matched requests, the combined time is 65.266 seconds, compared with 104.757 seconds for the matched native control and 103.134 seconds for the preceding application. These savings combine exact structure with the retained learned decisions. Table~\ref{tab:analytic-results} separately compares the exact fixed control so that analytic savings are not assigned to ML.

The seed and equation studies identify specific domains where learned decisions help. The tested row model does not establish an overall gain, so the current application retains native row choices. In the new comparison, the retained selector uses 6.4\% less time than the fixed control on the eight coupled nonplanar requests, with a repetition interval below one. The earlier sparse-expert test also records a regression on its new-index subset. These limits remain part of the evidence after the analytic extension.

The combined application and matched native and fixed controls use prepared master indices. The preceding application uses its earlier cache, and its timer retains any additional discovery work. Model training, master discovery, and independent reference preparation remain separate expenses. The tests cover scalar one-loop polygons, specified connected native blocks through three loops, and analytic families and independent products through thirteen loops. They establish useful exact and learned contributions within those domains, while general connected high-loop scattering and a globally minimum decomposition time remain open.

The final input rule avoids the more expensive symbolic-recurrence path exposed by two initial regressions. It completes all nine follow-up requests and uses 85.6\% less time on their four symbolic inputs than the initial analytic variant. This separate result supports choosing exact and native methods by measured total cost, while preserving the earlier ML comparison and its limits.
