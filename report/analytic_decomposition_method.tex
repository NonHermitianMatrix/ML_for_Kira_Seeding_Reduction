\section{Exact decomposition before learned selection}
\label{sec:analytic-method}
The form of an integral can remove work before a model makes a decision. Our application first separates independent loop-momentum blocks and uses available scalar and tensor formulas under their stated assumptions, as derived in Appendix~\ref{app:blocks13}. We add an exact recurrence for scalar one-loop blocks with raised propagator powers. This step extends the application to massive two-point, triangle, box, and pentagon families with a prepared compatible master basis. The remaining blocks retain the learned Kira choices described in the following sections.

The recurrence uses the matrix of masses and external momentum differences defined in Eq.~\eqref{eq:analytic-y}. Its dimension equals the number of active denominators, which is at most five in this implementation. Solving the IBP identities for that small matrix expresses a raised power through integrals with a smaller sum of powers. Repeating the step reaches unit-power sectors. Appendix~\ref{app:analytic-decomposition} derives the recurrence, proves termination, and explains why its coefficients can be computed with exact polynomial arithmetic in $d$. We use this established IBP structure to avoid general equation generation in its supported domain~\cite{ChetyrkinTkachov,Hu2025}.

The application checks the result against the supplied master indices and returns unsupported cases to Kira. It includes the check and any unsuccessful analytic attempt in the total time. This design allows exact formulas and learned choices to contribute to the same decomposition without assigning the analytic saving to ML. The current sparse-seed models remain frozen during the new analytic comparison, and the ML-free control uses the same analytic recurrence. Section~\ref{sec:analytic-results} reports these separate contributions.

The final input rule limits the new recurrence to direct rational kinematics. Symbolic inputs retain the earlier exact formulas or native Kira path, as tested in Section~\ref{sec:parser-guard}. The symbolic recurrence remains mathematically valid, but its fresh-process setup cost exceeded the native cost in the measured examples.
