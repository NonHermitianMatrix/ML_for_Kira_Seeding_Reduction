# Figures for the detailed experiment notes

These PDFs show the original model tests and Kira integration experiments. Seed plots report classification scores, ranked recovery, or equation sufficiency. Row-model plots report selected actions, completed trajectories, operation counts, and runtime. Kira plots compare native integration, prediction overhead, exact reuse, and other measured changes.

Use a plot’s filename and the corresponding section of `../notes.tex` to identify its experiment. Each model or comparison folder documents the plotting script and saved summary used to generate its figures. Plot values belong to that experiment’s reference method and input set.

The research paper’s principal plots are in [paper_figures](../paper_figures/README.md). [The document build guide](../README.md) explains rendering and checks. Changes to these figures require a new notes build; reading the existing PDFs requires no integral data or model loading.
