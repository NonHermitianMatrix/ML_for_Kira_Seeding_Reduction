# Logs

These text files contain scheduler output and progress messages. Use `../s03_job.sh` to submit jobs. Full scientific records are in the other study folders. Do not use log timing as a replacement for the saved complete-time records.

See the [study guide](../README.md) for inputs, commands, dependencies, and limits. Data stay on Hoffman and GitHub.

These records belong to selection of integral ordering. Use matching case identifiers when combining files.
