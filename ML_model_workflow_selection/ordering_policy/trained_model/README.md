# Trained model

The `candidates.json` file stores all seventy fitted predictors. The `freeze.json` file stores the selected policies, controls, domain guards, and source checks. Run `../s05_fit.py` to fit and freeze. Run `../s07_reduce.py` to apply the frozen route. Do not refit after reserved tests.

See the [study guide](../README.md) for inputs, commands, dependencies, and limits. Data stay on Hoffman and GitHub.

These records belong to selection of integral ordering. Use matching case identifiers when combining files.
