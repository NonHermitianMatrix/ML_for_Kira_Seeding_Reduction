# Native reference reductions

These compressed JSON records contain native reductions from enlarged seed regions.
They provide the prescribed master basis and independent target coefficient checks.
Each record gives the integral family, targets, Kira inputs and exact output.
The main study uses one reference for each of its 79 target batches.
Reference discovery remains outside the repeated reduction timer.
Joint-request references are stored with that separate comparison.

Read [the parent guide](../README.md) for the generating code, commands and resource limits.
