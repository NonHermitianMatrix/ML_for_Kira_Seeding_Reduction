# Logs

These logs record scheduled development, fitting, validation, testing, and analysis. They retain failures and corrected continuations. The scheduler wrapper s01_job.sh produces them.

The training_corrected.log file records the corrected training and validation runs.
The pairing.log file records the repeated comparisons and final model fit.
The test_corrected.log file records the reserved tests, application checks, and final audit.
Earlier logs preserve the development and replaced measurements.
Use the final summary and audit to identify completed results.

See the [study guide](../README.md) for input definitions, script order, dependencies, and limits.
