# Development records

These files preserve initial ordering and seed-bound probes on development inputs.
`initial_case_protocol.json` preserves the first cost-collection plan.
`initial_candidates.json` and `initial_model_freeze.json` preserve the first nine-model comparison.
The final comparison adds three tree settings before any reserved test.
The saved probes include failed reductions and their measured costs.

Read [the parent guide](../README.md) for code, execution order and resource limits.

`initial_resource_plan.json` preserves the earlier storage reservation.
The final plan adds room for both PDFs, publication copies and local review files.
