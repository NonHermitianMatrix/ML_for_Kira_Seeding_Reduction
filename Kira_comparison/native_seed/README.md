# Native Kira seed bounds

The seven independent-basis families use their largest frozen batches, with 99 distinct target expressions, four methods and three repeats. The methods are the learned per-sector seed envelope, the one-unit-margin native baseline, that baseline with documented subsector truncation and dot bounds, and a deterministic control with bounds equal to the largest target/master indices. The learned envelope and target-index control use the same bounded default fallback. Kira generates the equations for every method and performs the exact component reduction; Kira/Fermat then combines component expansions.

plan.json fixes methods, targets and limits. frozen_inputs.json records the executed sources and unchanged models. Earlier pre-execution freezes remain as diagnostic records; no full native trials used them. storage_guard_extension.json and resumption_validation.json document the later storage-only resumption: one complete family is preserved, and two interrupted family groups are repeated in full on a single node. The original 14 partial-family trials remain in storage_guard_partial/ and are excluded from the final 84-trial comparison. results/ contains every bounded trial, including its configurations, solver exports and logs. validation.json checks the full grid, actual native seed bounds and master coefficients at independent points. summary.json records matched case medians, completion counts and native equation counts, which refer to component reduction before the separately timed combination. ../cost_breakdown.json separates measured stages. Reproduction uses ../s14_prepare_native.py, ../s12_native_array.sh and the audits and summaries documented in the parent README.

The comparison is complete and independently checked. The main experiment contains 792 trials in 19 family cases; the direct native seed-bound comparison contains 84 trials in seven independent-basis families. Against Kira with the full stored source pool, learned seeds have geometric mean complete-process/prepared-input time ratios 1.720/1.116, and learned rows have ratios 1.719/1.205. Learned native seed bounds have ratios 1.596/1.344 against default native bounds and 1.671/1.373 against restricted native bounds. Against the control with seed bounds taken directly from target indices, the native learned ratios are 1.425/1.141. Ratios use matched case medians from three repeats; values below one indicate lower time. Complete-process time includes loading, inference, exact algebra, fallback and coefficient checks. Prepared-input time excludes family and model loading. Completion counts, all resource outcomes, individual cases and operation measures appear in summary.json and native_seed/summary.json. The direct native test learns sector envelopes. The row model still acts on fixed source identities and changing target rows.
