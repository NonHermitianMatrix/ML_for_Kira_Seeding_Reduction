# Development

Initial bounded native probes. The records include time, memory, allocation, and family-size limits.

Read the [study guide](../README.md) for the producer scripts, input definitions, units, and limits.
Do not edit a completed record.
Use the analysis script to read the compressed JSON files.
Failed records remain part of the evidence.

These records belong to separate contributions to native scattering reduction time. Use matching case identifiers when combining files.
