# Training: selection of IBP equations

These records supply training inputs or measured labels for selection of IBP equations. Keep their family assignments separate from validation and reserved tests.

This folder retains an earlier stage, development check or saved comparison.
Use its records to interpret that stage.
Use the current parent application for a new calculation.
