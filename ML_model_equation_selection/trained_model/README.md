# Selection of IBP equations

This folder stores the fitted models for selection of IBP equations. Model files contain the parameters used for prediction; validation records identify the accepted choice.

## Data and supporting files

- [confirmation_freeze.json](confirmation_freeze.json): Identifiers, file locations, or fixed settings used to reproduce this calculation.

- [deployment.json](deployment.json): Saved deployment.json record for selection of IBP equations; the producer code defines its fields.

- [deployment_confirmed.json](deployment_confirmed.json): Saved deployment_confirmed.json record for selection of IBP equations; the producer code defines its fields.

- [deployment_final.json](deployment_final.json): Saved deployment_final.json record for selection of IBP equations; the producer code defines its fields.

- [deployment_report_values.json](deployment_report_values.json): Saved deployment_report_values.json record for selection of IBP equations; the producer code defines its fields.

- [deployment_verification.json](deployment_verification.json): This file records checks of the corresponding calculation.

- [freeze.json](freeze.json): This file identifies the fixed inputs and method for the completed test.

- [model.json](model.json): This file contains a saved model or its description.

- [weights.txt](weights.txt): This file contains a saved model or its description.
