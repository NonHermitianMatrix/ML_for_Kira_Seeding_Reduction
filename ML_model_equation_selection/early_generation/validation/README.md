# Validation: equation selection before coefficient construction

These measurements select the model or fixed setting for equation selection before coefficient construction. They are separate from the reserved test results.

## Data and supporting files

- [candidates.json](candidates.json): Saved candidates.json record for equation selection before coefficient construction; the producer code defines its fields.

- [composition_summary.json](composition_summary.json): Result counts and measured outcomes; interpret them with the stated comparison and limits.

- [final_selection.json](final_selection.json): Saved final_selection.json record for equation selection before coefficient construction; the producer code defines its fields.

- [prediction_parity.json](prediction_parity.json): Predicted labels, scores, or selected actions for the supplied examples.

- [storage_integrity.json](storage_integrity.json): Saved storage_integrity.json record for equation selection before coefficient construction; the producer code defines its fields.

- [summary.json](summary.json): This file contains the result counts and summary measurements.
