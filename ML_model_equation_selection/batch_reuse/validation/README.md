# validation

This folder contains validation records.
These records select a method before the reserved test.

Read [the parent guide](../README.md) for the stage and data flow.

The producing and reading code is described in [the stage guide](../README.md).

## Data and supporting files

- [arithmetic_check.json](arithmetic_check.json): This file records checks of the corresponding calculation.

- [native_complete.json](native_complete.json): This file contains structured records from the parent calculation.

- [pack_complete.json](pack_complete.json): This file contains structured records from the parent calculation.

- [pilot_complete.json](pilot_complete.json): This file contains structured records from the parent calculation.

- [pilot_scheduler.log](pilot_scheduler.log): This file contains saved program messages.

- [scheduler.log](scheduler.log): This file contains saved program messages.

- [validation_complete.json](validation_complete.json): This file contains structured records from the parent calculation.
