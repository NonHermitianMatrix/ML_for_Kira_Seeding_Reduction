# Validation: reuse of compatible equations across target batches

These measurements select the model or fixed setting for reuse of compatible equations across target batches. They are separate from the reserved test results.

## Data and supporting files

- [arithmetic_check.json](arithmetic_check.json): This file records checks of the corresponding calculation.

- [native_complete.json](native_complete.json): Saved native_complete.json record for reuse of compatible equations across target batches; the producer code defines its fields.

- [pack_complete.json](pack_complete.json): Saved pack_complete.json record for reuse of compatible equations across target batches; the producer code defines its fields.

- [pilot_complete.json](pilot_complete.json): Saved pilot_complete.json record for reuse of compatible equations across target batches; the producer code defines its fields.

- [pilot_scheduler.log](pilot_scheduler.log): This file contains saved program messages.

- [scheduler.log](scheduler.log): This file contains saved program messages.

- [validation_complete.json](validation_complete.json): Recorded checks of the calculation, data, or selected settings.
