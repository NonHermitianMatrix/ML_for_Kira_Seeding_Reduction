# Training: reuse of compatible equations across target batches

These records supply training inputs or measured labels for reuse of compatible equations across target batches. Keep their family assignments separate from validation and reserved tests.

## Data and supporting files

- [compact_check.json](compact_check.json): This file records checks of the corresponding calculation.

- [examples.json.gz](examples.json.gz): Saved examples.json.gz record for reuse of compatible equations across target batches; the producer code defines its fields.

- [native_check.json](native_check.json): This file records checks of the corresponding calculation.

- [summary.json](summary.json): This file contains the result counts and summary measurements.
