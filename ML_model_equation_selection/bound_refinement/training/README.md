# Training

Sampled training labels from exact reductions with tuned seed bounds.
Read [the parent guide](../README.md) for commands and data definitions.

The numbered scripts in the parent folder produce these files.
Read compressed JSON files directly. Do not keep uncompressed data copies.
Preserve failures and exact coefficient checks.
Do not mix training, validation, and reserved records.

These records belong to refined equation selection from seed and target indices. Use matching case identifiers when combining files.
