# integration

This folder contains reserved test inputs, outputs or checks.
Keep these records outside model fitting and threshold selection.

Read [the parent guide](../README.md) for the stage and data flow.

The producing and reading code is described in [the stage guide](../../README.md).

## Data and supporting files

- [default_cli.json](default_cli.json): This file contains structured records from the parent calculation.

- [default_input.json](default_input.json): This file contains structured records from the parent calculation.

- [direct_analytic.json](direct_analytic.json): This file contains structured records from the parent calculation.

- [direct_extreme.json](direct_extreme.json): This file contains structured records from the parent calculation.

- [direct_model.json](direct_model.json): This file contains a saved model or its description.

- [direct_model_failure.json](direct_model_failure.json): This file contains a saved model or its description.

- [summary.json](summary.json): This file contains the result counts and summary measurements.
