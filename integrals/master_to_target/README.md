# Exact coefficients, identities, and reduction traces

Each family folder connects target expressions to their master expansions. It stores candidate seeds, source identities, construction records, and elimination steps. Reference paths are sufficient reductions; they are not certificates of minimum cost.

`catalog.json` indexes the collection. [families/](families/README.md) contains one directory per family instance. Use the same folder name in the other integral categories.

[The collection guide](../README.md) gives the data counts, split rules, and streaming reader commands.

`generation_source.tar.gz` and `generation_source_manifest.json` preserve the generation source. `split_overlap_witnesses.json` records overlap information used to keep related profiles together.
