# Initial application loading

These records preserve the application before deferred loading of the previous-workflow service.
The first initializer loaded that service before every use of the interface.
The current interface loads it only if a request selects the previous workflow.
The fitted models and policy choices remain unchanged.
The archived source belongs at its original parent-folder path when reproducing the former interface.
Read the [study guide](../README.md) for the current code and limits.
