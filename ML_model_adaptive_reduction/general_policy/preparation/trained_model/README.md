# Trained model

The saved forest predicts log attempt time and a scaled failure label. freeze.json contains weights, sources, candidate scores, and selection. selection.json gives the short result. s15_risk.py produces both files. The exported evaluator passes comparison with the training library on all training inputs.

Read [the preparation guide](../README.md) for inputs, run order, and limits.

These records belong to a shared structural model for seed costs. Use matching case identifiers when combining files.
