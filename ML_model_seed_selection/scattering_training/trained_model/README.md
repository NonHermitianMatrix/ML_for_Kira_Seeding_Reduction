# Fitted seed trees

Each JSON file contains a seed tree and its training provenance.
Its matching text file contains the same fitted parameters for native inference.
The trees use sixteen features and omit the operator feature.
One score therefore controls all equations from a seed.
The selected threshold is stored in the shared study's `freeze.json`.

Read [the parent guide](../README.md) for the training code and data.
The native text layout is described in the [equation model guide](../../../ML_model_equation_selection/scattering_training/trained_model/README.md).
