# Scattering seed test summary

`summary.json` gives the seed model results from the shared reserved test.
It includes exact completion, fallback counts and full-time ratios.
The full reduction records remain in the shared folder and are not duplicated here.

Read [the shared test guide](../../../ML_model_equation_selection/scattering_training/model_test/README.md).
Use the analysis script stated in [the parent guide](../README.md) to reproduce this summary.

These records belong to training and testing on specified scattering structures. Use matching case identifiers when combining files.
