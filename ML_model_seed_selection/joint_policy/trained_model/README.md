# Trained model

These files store fitted tree arrays and validation decisions.
Files with the fixed prefix contain no model weights.
Freeze files identify the code and parameters used before reserved tests.
The application reads the validation decision before loading any new predictor.
Both current decisions retain the preceding application.

Read [the parent guide](../README.md) for producers, readers, dependencies, and limits.

These records belong to joint seed and Kira-configuration selection. Use matching case identifiers when combining files.
