# Matched validation

These records repeat the second nonplanar validation profile with every candidate and control on one worker.
The original worker had no free memory for a later control job.
The repeat protocol was recorded before these measurements and before any nonplanar reserved test.
The refit script copies these checked records into the active validation folder.

Read [the parent guide](../README.md) for producers, readers, dependencies, and limits.

These records belong to joint seed and Kira-configuration selection. Use matching case identifiers when combining files.
